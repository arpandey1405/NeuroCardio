      Feature importance

      Read this before quoting accuracy. data.csv is 100 synthetic rows and the two classes do not overlap on any feature, so every model scores 100%. That number is not meaningful; real figures need annotated records (MIT-BIH / PTB-XL) in Review 2.

      Signal chain

      ATmega328P firmware → USB serial → host classifier

      1. ADCA0 / A1 · 200 Hz
      2. 4-tap moving averagenulls at 50 & 100 Hz
      3. IIR high-pass~0.12 Hz, baseline wander
      4. R-peak detectoradaptive 3/5 envelope · 250 ms refractory
      5. P / Q / R / Svs. local TP isoelectric line
      6. Serial115200 baud · B, D lines
      7. Random Forest200 trees on (P, Q, R) · SNN in Review 2

      Sampling · 200 Hz

      Covers QRS detection and rate; chosen together with the 4-tap average so its spectral zeros land exactly on 50 Hz mains and its 100 Hz harmonic.

      Baseline removal

      baseAcc += maSum − (baseAcc >> 8) tracks a 1.3 s running mean; subtracting it removes electrode offset and breathing drift while keeping the P wave.

      R-peak detection

      Idle → rising → wait state machine. Threshold at 3/5 of a decaying peak envelope plus a 250 ms refractory period, so a T wave is never counted (240 bpm ceiling).

      Lead-off watchdog

      If more than 10% of samples in a 1 s window are railed, the device shows LEAD OFF - CHECK instead of reporting a fake 200 bpm.

      On-device screen

      2-of-3 thresholds (P > 0.28, Q < −0.33, R > 1.05 mV) plus brady < 50 / tachy > 120 bpm, confirmed over 3 consecutive beats before the buzzer alarms.

      Calibration

      5000 mV ÷ 1024 counts ÷ gain 1000 = 0.004883 mV/count. Press c on a clean beat and the firmware solves for the gain that makes R read 1.00 mV.

      Limitations & roadmap

      • Synthetic training data. 100 separable rows; accuracy is not meaningful yet.
      • Single lead, three electrodes. Rate and gross morphology only; not 12-lead diagnosis.
      • Not a medical device. No isolation barrier or certification; research prototype.
      1. Acquisition & feature front end
      2. Host classifier + web dashboard
      3. Real annotated dataset (MIT-BIH / PTB-XL)
      4. Spike-encode features, train the SNN
      5. Port inference to the device
